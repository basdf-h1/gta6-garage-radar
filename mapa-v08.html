GARAGE RADAR · MAPA PROPIO v0.8

🗺️ Leonida · Mapa interactivo

Visor preparado para una imagen de cartografía cuyo uso esté autorizado. Las posiciones se registran sobre la propia imagen: no son coordenadas GPS.

Todavía no hemos incorporado una imagen oficial autorizada ni coordenadas verificadas. Puedes cargar una imagen para uso local y ubicar marcadores manualmente. No publiques una imagen de terceros en GitHub sin permiso de reutilización.

1. Cargar cartografía autorizada

Sin imagen cargada. La imagen elegida se conserva solo en este navegador mediante IndexedDB; no se envía a Supabase ni a GitHub.

2. Explorar y colocar puntos

Selecciona un vehículo y pulsa «Colocar punto». Después toca la ubicación sobre la imagen. El marcador queda sin verificar hasta que aportes evidencia de la partida.

Carga una imagen autorizada para comenzar

Pellizca para zoom, arrastra para desplazarte. En modo «Colocar punto», toca la imagen para registrar coordenadas relativas X/Y (0–1). Las coordenadas no tienen validez sin cartografía y calibración.

3. Marcadores registrados en este dispositivo

Los reportes iniciales siguen disponibles como referencias, pero no se han proyectado artificialmente sobre una cartografía no calibrada.

Arquitectura y fuentes

Imagen autorizada → visor Leaflet CRS.Simple → coordenadas normalizadas → registros locales. Próxima etapa: tablas RLS de Supabase para compartir ubicaciones verificadas y separar observaciones privadas.
