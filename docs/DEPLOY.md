# GTA VI Garage Radar — Publicación

1. En el repositorio, abrir Settings > Pages.
2. En Build and deployment, elegir Deploy from a branch.
3. Elegir `main` y carpeta `/(root)`; guardar.
4. Abrir https://basdf-h1.github.io/gta6-garage-radar/ cuando GitHub indique publicación correcta.
5. En iPhone usar Safari > Compartir > Agregar a pantalla de inicio.

Datos personales guardados solo en almacenamiento local; usar Exportar respaldo JSON para respaldar. Catálogo inicial sujeto a verificación.
