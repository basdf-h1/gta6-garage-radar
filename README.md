# GTA VI Garage Radar v0.2

PWA para iPhone: catálogo de vehículos, favoritos, colección, bitácora y mapa esquemático interactivo.

Sitio: https://basdf-h1.github.io/gta6-garage-radar/

## Mapa v0.2
- Pestaña **Mapa**: zonas de Port Gellhorn con marcadores seleccionables y fichas asociadas.
- Filtros por tipo de vehículo y vehículos conseguidos.
- Enlaces a GTABase para abrir ubicaciones precisas en su mapa de GTA VI.
- El mapa incorporado es **un esquema conceptual, no una cartografía fiel ni coordenadas exactas**. Sus posiciones se eligieron para separar los marcadores visualmente, no para representar la realidad geográfica.
- Las ubicaciones reportadas de vehículos aún requieren validación dentro del juego y las fichas lo indican.

## Persistencia
Conserva el mismo `localStorage` (`garage-radar-v01`) para mantener tu progreso de la versión anterior. Para respaldar: **Garaje → Exportar respaldo JSON**.
